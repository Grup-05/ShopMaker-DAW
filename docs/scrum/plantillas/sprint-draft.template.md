# Plantilla de Borrador de Sprint — ShopMaker-DAW

Esta plantilla se encuentra estandarizada y versionada en:
👉 [draft-specs/sprint-draft.template.md](../../../draft-specs/sprint-draft.template.md)

Consulta ese archivo para obtener la estructura obligatoria de los borradores preparatorios de cada Sprint, incluyendo:
1. Rotación circular de roles Scrum.
2. Formato del Sprint Goal.
3. Desglose en 3 Workstreams paralelos desacoplados por Puertos y Adaptadores.
4. Tabla oficial de PBIs y Matriz Atómica de Tareas (≤ 8 h por tarea).
5. Directriz multiplataforma para creación de issues (autodetección Windows vs Linux / fallback interactivo).
6. Protocolo de verificación obligatoria post-creación (*Verify & Assert*).
7. Checklist de Definition of Ready (DoR) del Tablero.
